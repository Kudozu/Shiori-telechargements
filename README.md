# Shiori 栞 — téléchargements

Shiori : regarder les animes et lire les scans d'Anime-Sama, avec suivi de progression, téléchargements hors ligne et synchronisation entre appareils.

**Dernière version : [page des téléchargements](https://github.com/Kudozu/Shiori-telechargements/releases/latest)** → fichier **Shiori.zip**.

Le zip est protégé par un **mot de passe** : demande-le à l'ami qui t'a envoyé ce lien. Il contient l'app Android (`Shiori.apk`) et l'installateur Windows (`Shiori-Setup.exe`).

## Android

1. Sur ton téléphone, ouvre la page des téléchargements et touche **Shiori.zip**.
2. Ouvre le zip avec une app qui accepte les mots de passe (par exemple **ZArchiver**, gratuite sur le Play Store), tape le mot de passe et sors **Shiori.apk**.
3. Touche **Shiori.apk**. Android demande d'autoriser « Installer des applis inconnues » : accepte, puis **Installer**.

Les mises à jour arrivent ensuite toutes seules dans l'app (un bandeau propose de redémarrer Shiori) : rien à réinstaller.

## Windows

1. Télécharge **Shiori.zip**, fais un clic droit → **Extraire tout**, et tape le mot de passe.
2. Lance **Shiori-Setup.exe**. Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même* (l'installateur n'est pas signé).
3. *Installer*. Les mises à jour arrivent ensuite dans l'app.

## Compte

Onglet **Compte** (sur téléphone : **Moi → Connexion**) : crée un compte avec un code d'invitation donné par un ami, ou connecte-toi.
