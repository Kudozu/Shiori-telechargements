# Shiori 栞 — téléchargements

Shiori : regarder les animes et lire les scans d'Anime-Sama, avec suivi de progression, téléchargements hors ligne et synchronisation entre appareils.

**Dernière version : [page des téléchargements](https://github.com/Kudozu/Shiori-telechargements/releases/latest)**

À la première ouverture, Shiori demande un **code d'accès** : demande-le à l'ami qui t'a envoyé ce lien. Il n'est demandé qu'une fois.

## Android

1. Sur ton téléphone, ouvre la page des téléchargements et touche **Shiori.apk**.
2. Ouvre le fichier téléchargé. Android demande d'autoriser « Installer des applis inconnues » pour ton navigateur : accepte.
3. Touche **Installer**, puis ouvre Shiori et entre le code d'accès.

Les mises à jour arrivent ensuite toutes seules dans l'app (un bandeau propose de redémarrer Shiori) : rien à réinstaller.

## Windows

1. Télécharge **Shiori-Setup.exe** et lance-le.
2. Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même* (l'installateur n'est pas signé).
3. *Installer*, puis ouvre Shiori et entre le code d'accès. Les mises à jour arrivent ensuite dans l'app.

## Compte

Onglet **Compte** (sur téléphone : **Moi → Connexion**) : crée un compte avec un code d'invitation donné par un ami, ou connecte-toi.
